# Dungeon Journal prose: one set of words

All six `uk_*.lua` files follow this list. Order of choice: the glossary first, then the word used most, then the clearest one.

| English | Ukrainian | Why |
|---|---|---|
| NPC (person, "talk to X", "report to X") | НІП «X» (does not change form); "Report to X" → «Поверніться з доповіддю до НІП «X»» | glossary |
| Boss you must kill | боса «X» | clearer than НІП for a kill target |
| Defeat | Здолайте | most used (11 vs 10 «Переможіть») |
| Recover / obtain | Здобудьте | most used (24 vs 8 «Добудьте») |
| Go to (a dungeon) | Вирушайте до | most used (56 vs 3 «в») |
| Drops from | випадає / випадають | most used (26 vs 11 «падає») |
| Step (of a chain) | крок; "Останній крок" | most used (43 vs 13 «етап») |
| Leads into quest | Вступний крок до завдання | shortest of three forms |
| Required before | Потрібне перед завданням | plain word |
| Mage class quest | Класове завдання мага | singular, like the other classes |
| Subzone (town, camp, area) | місцевість «X» | house style; локація stays only for top-level zones |
| Stone Watcher | Кам'яний вартовий | one name in all files |
| Cathedral District | у кварталі «Cathedral District» | name in «» like other places |
| Count of items | «X»: N шт.; a count of 1 → «1 предмет «X»» | house style; the number must stay (build check) |
| Count of creatures (kill / free N) | «X»: N, no «шт.» (e.g. «Убийте «X»: 8 і «Y»: 8») | «шт.» is for things, not living beings |
| Bring / take / deliver / return an item to X | «Принесіть / Віднесіть / Доставте / Поверніть … до НІП «X»» | one form for carrying something to a person |
| Hand / give / turn in / tell X | «Віддайте / Передайте / Здайте / Розкажіть … НІП «X»» (no «до») | these verbs take the person directly |
| "the X" place names (The Rookery, The Sepulcher) | місцевість «X»; top-level zones (The Barrens, The Hinterlands) → локація «X» | same rule as other places |
| Two places "Town, Zone" | місцевість «Town» (локація «Zone») | two names, two placeholders |
| Discord (the source's chat) | Discord аддона Dungeon Journal | says whose Discord it is |
| Generic mobs (no placeholder) | Ukrainian plural, e.g. «10 змучених душ» | reads naturally |
| Clan / faction words | the UALLF form, the same everywhere: Дефіаси (Братство Дефіас), Темне Залізо, Драконяча Паща, Сухокори, Кривава Сокира, Ґордоки, Земляне Кільце, Палаючий Клинок, Пилоригачі, Багноплавці, Мародіни, Маґрами, Ґелкіси, Страшази, Тіньова Кузня, Кам'яне Сховище, Кор'крон, SI:7, Тліючий Шип (клан Тліючого Шипа), Шпилекамінь (клан Шпилекаменя) | UALLF already names them |
| Name with a placeholder in src | write the placeholder with its noun: НІП «{npc:X}», місцевість «{zone:X}», завдання «{quest:X}», предмет «{item:X}» | the build fills in the Ukrainian name |
| "X's Y" where X is a placeholder | «Y НІП «{npc:X}»» / «Y місцевості «{zone:X}»» | the placeholder never changes form, the noun does |
| Short or partial name (Jaina, Magni, Thaurissan) | the UALLF Ukrainian of the same part: Джайна, Маґні, Тауріссан | UALLF has the full name |
| Name UALLF does not have | keep the English in «», e.g. «Mithera», «Toxic Soil» | no Ukrainian to copy |
| Site / product names (Forever, Classic, Mobalytics, Wowhead) | stay English, no «» | they are not game names |
| BRD / UBRS / LBRS | Глибини Блекрок / Верхній Шпиль Блекрок / Нижній Шпиль Блекрок | UALLF dungeon names |

Kept as they were: Зброярня / Собор / крило «Library» for Scarlet Monastery wings, допуск (attunement), інстанс, Орда, Альянс.
